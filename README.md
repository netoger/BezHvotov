# Без хвостов

Исходники статического сайта «Без хвостов». На сайте можно посмотреть направления консультаций и цены, выбрать костюм ёжика и перейти в Telegram-канал. [Открыть сайт](https://beshvostov.ru/)

Для сборки нужен Node.js 22 или новее. Устанавливать зависимости не требуется.

```sh
npm test
npm run build
npm run preview
```

В PowerShell можно использовать `npm.cmd` вместо `npm`. Локальный просмотр доступен на [127.0.0.1:4173](http://127.0.0.1:4173/). Готовые файлы находятся в `dist/`. Команда `npm run build:preview` собирает вариант с запретом индексации.

Общие тексты и SEO-настройки лежат в `content/site.json`, направления и их прайсы — в `content/directions.json`. Аксессуары ёжика хранятся в `src/assets/mascot/costumes/`.
